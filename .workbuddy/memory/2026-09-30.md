## 首启 BugFix ②：dev 端口 5173 落入 Windows 排除端口段
- 报错：`listen EACCES: permission denied 0.0.0.0:5173`（vite dev server 启动即失败）
- 诊断：`netsh interface ipv4 show excludedportrange protocol=tcp` 显示本机 TCP 排除段含 **5153-5252**（Hyper-V/WSL 动态保留，重启后会漂移，聚集区约 4200-9600）；netstat 确认 5173 无进程占用——是系统保留段拦截，与权限/占用无关
- 修复（3 处）：① vite.config.ts 端口 5173→**3000**（node 瞬时探测 3000/5273/8000/8080 全部可绑，选离排除段聚集区最远的）+ host true→'localhost'（免 Windows 防火墙首次弹窗，注释保留手机预览改回 true 的说明）；② start-frontend.bat 提示语 URL 同步；③ README.md 运行说明同步 + 端口说明注
- **教训（QA 检查项）**：Windows 上 Vite 端口报 EACCES，第一步查 `netsh interface ipv4 show excludedportrange protocol=tcp`；选 dev 端口避开 4200-9600 排除段聚集区；node 瞬时 listen/close 探测是毫秒级验证手段
- 附带说明：npm install 提示 4 vulnerabilities（vite 5 依赖链，3 moderate 1 high）——开发环境风险低，**暂不处理**；已提醒用户勿跑 `npm audit fix --force`（会破坏依赖树），待将来升 Vite 大版本自然消掉
