## 数据采集方法建议

### 分省招生计划数据
- **方法1**：从各省教育考试院官网下载《招生专业目录》PDF
- **方法2**：使用阳光高考平台的招生章程查询接口逐校采集
- **方法3**：使用高考100等聚合平台的省份数据页面批量采集

### 位次表数据
- 各省教育考试院官网直接发布，通常为PDF或HTML格式
- 建议使用playwright-cli自动化采集

### 专业招生详情
- 需逐校从高校官方招生网采集
- 数据量极大，建议分批处理
