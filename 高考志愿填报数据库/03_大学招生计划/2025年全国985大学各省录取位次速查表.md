## 使用说明

- **"985门槛位次"** = 该省物理类/理科能被985录取的最低位次（即最低分985的最低录取位次）
- **"Top10门槛位次"** = 该省能上C9/华五等顶尖985的预估位次
- **"强211门槛位次"** = 能上北邮/西电/央财等热门211的位次
- **位次稳定原则**：同校同省录取位次年波动通常≤5%

## 位次填报三步法

### 第一步：换算你的2026位次
用2026年一分一段表查出你的分数对应位次（例如广东物理类30000名）。

### 第二步：对标2025位次
在本文各省份表中找到你所在省份，看你的位次落在哪个985区间。

| 你的位次 | 广东物理类举例 |
|----------|--------------|
| 前500 | 冲清北 |
| 500-3000 | 冲华五/C9 |
| 3000-8000 | 中坚985（武大/中山） |
| 8000-20000 | 中尾985（华工/兰大/厦大） |
| 20000-40000 | 985门槛（吉大/西北农林） |
| 40000-105000 | 捡漏985+强211 |

### 第三步：冲/稳/保三梯度
- **冲**（2-3所）：位次高出你20%以内的学校
- **稳**（3-4所）：位次与你±5%的学校
- **保**（2-3所）：位次低于你20%+的学校
