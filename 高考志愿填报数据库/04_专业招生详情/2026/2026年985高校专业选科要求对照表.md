# 2026年985高校专业选科要求与选科组合对照表

> 数据来源：教育部选科指引(2025年12月)、gk100.com、各省教育考试院 | 更新日期：2026-06-29
> 注：2026年全国29个新高考省份已全面实行"3+1+2"模式

---

## 一、核心规则：物化绑定

### 2026年选科三大核心变化

1. **物化绑定强化**：超63%的理工类专业要求"物理+化学"双选
2. **赋分制改革**：化学从"选科冷门"变为"理工刚需"
3. **专业覆盖率分化**：选科组合间差距巨大

### 关键数据

| 选科组合 | 专业覆盖率 | 核心优势 |
|----------|----------|----------|
| 物理+化学+政治 | **737专业（最高）** | 覆盖12学科门类，军警法+理工医 |
| 物理+化学+生物 | 高（纯理科） | 医学+生物科学，传统黄金组合 |
| 物理+化学+地理 | 较广 | 工科+经管+农学+医学可选 |
| 物理+政治+生物 | 下降 | 经管+农学+医学，缺化学受限 |
| 物理+生物+地理 | 适中 | 逻辑思维强，化学不佳的考生 |
| 物理+政治+地理 | 较低 | 竞争小，但专业面窄 |
| 历史+化学+政治 | 有限 | 文保技术+药学+公安政法 |
| 历史+化学+地理 | 与历生地相似 | — |
| 历史+生物+政治 | 较低 | 园林需生物必选 |
| 历史+化学+生物 | 较低 | 思维跨度小 |
| 历史+生物+地理 | 较低 | 历学+旅游+园林 |
| 历史+地理+政治 | 较低 | 经典文科组合 |

## 七、2026年选科趋势总结

1. **物化绑定已成铁律**：63%以上理工专业要求物理+化学双选
2. **不选化学=放弃大部分理工**：仅有约22%的理工专业不要求化学
3. **历史类考生空间收窄**：985工科/医学几乎全部要求物理类
4. **物理+化学+政治是2026年最优组合**：专业覆盖率737个，覆盖12学科门类
5. **赋分制下化学不再是冷门**：化学从选考冷门变为理工刚需
